# Security

This is a small educational script. To report a bug, a false alarm, a missed
pattern, or a way the scanner itself could be tricked into running something,
please **open a GitHub issue** in this repository.

Please don't paste real secrets, live malware, or full malicious payloads into
an issue. A short description, the file path pattern, and a harmless example
(using `echo` and `example.invalid`) are enough.

The scanner is designed never to execute code from the repo it reads and never
to use the network. If you find a case where it does, that's the most important
kind of issue to report.
